## Separately acquired TC002 development SDK

The official FlyThings SDK/toolchain is downloaded into ignored `.cache/` for
local compilation. Package hashes and origin URLs are pinned by the TC002 build
script. It includes vendor interfaces, libcurl, mbedTLS, c-ares, zlib, FFmpeg
components and GNU/Linux runtime libraries, each under its own terms. SDK system
`.so` link stubs are not functional replacements for device libraries and must not
be installed on the clock.

Do not infer permission to redistribute vendor SDK binaries from this project's
GPL license. Before public distribution, audit the full static-link closure,
obtain corresponding sources/build instructions for copyleft components, verify
vendor permissions and document the device-system-library boundary. Current
device bundles are local engineering artifacts, not a public release.

The CA bundle comes from [curl's Mozilla CA extract](https://curl.se/docs/caextract.html),
with provenance and notices retained in the file (Mozilla Public License 2.0).
The synthetic alarm PCM is generated by this project, with no sampled third-party
audio. Windows HTTPS uses WinHTTP; other targets use libcurl with mandatory peer
and hostname verification.

Owlet service protocol facts were cross-checked against the original Owlanzi
client and the projects it credits: [pyowletapi](https://github.com/ryanbdclark/pyowletapi)
and [owlet_monitor](https://github.com/mbevand/owlet_monitor). No private account
credentials or local developer seed files are included.
